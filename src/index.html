Rescue Support

A small, open script that lets one trusted person help fix your Windows 10 PC remotely. It only runs when you start it, and you can remove everything afterwards.

What it does

  • Installs Windows' own OpenSSH Server and Tailscale (downloaded from tailscale.com; checksum and signature are verified).
  • Allows SSH only from Tailscale addresses. Nothing is opened on your router.
  • Adds one marked SSH public key for the helper. Windows still asks for a key or your password.
  • Asks you to type Y before it changes anything.

What it never does

It does not turn off Defender or UAC, create accounts, set passwords, or upload anything.

Read it first

rescue.ps1 (installer), r (launcher), diag.ps1 (optional read-only diagnostics), SHA256SUMS. Source: github.com/crossainthero-lab/fix.

Remove everything

C:\ProgramData\RescueSupport\uninstall.cmd

Run it from an Administrator Command Prompt.
